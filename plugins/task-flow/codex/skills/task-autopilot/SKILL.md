description: Plan, run, and resume a batch of Task Flow worktree tasks under the repository policy and circuit breaker.
---

Read [Autopilot in Codex](../../autopilot.md) before starting. Accept a
requirements description, `--from-repo`, `--tasks <id>[,<id>...]`, or an
existing run ID. Use the same profile overrides as `task-run` and honour the
shared Autopilot mode, budget and resume options.
